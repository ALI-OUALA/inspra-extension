When updating `chrome.storage` from UI text inputs in React, bind local state updates to `onChange` and execute async IPC storage writes on `onBlur` to prevent excessive IPC calls and rate-limiting. Crucially, implement a `visibilitychange` event listener to flush pending state to storage when `document.visibilityState === 'hidden'`. To avoid data-loss race conditions, store the pending state in a `useRef` and update this ref synchronously within the `onChange` handler. Furthermore, use an additional 'dirty' ref (e.g., `isDirtyRef`) to track unsaved edits and prevent asynchronous background storage updates from overwriting un-flushed pending states.
