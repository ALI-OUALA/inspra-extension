# Contributing

Thanks for improving Inspra.

Keep the product focused on inspiration intelligence, not cloning.

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run typecheck
npm run build
```

## Contribution Rules

- Preserve local-first behavior.
- Do not add scraping, cloning, or source-site copying workflows.
- Keep broad extension permissions explained in onboarding and release notes.
- Add user-visible error states for new provider, capture, or feedback flows.
- Keep generated skills centered on surface, principle, transfer, and boundary.
